01 2025

Agentic AI and LLMs in Fuzz Testing and Harness Development

Investigated whether Agentic AI can automate fuzz-harness development for FRRouting (FRR), a complex suite of stateful network daemons. The project adapted Light-Fuzz-Gen using an embedded fuzzing strategy that preserves daemon initialization state and internal dependencies.

7.61%Total FRR line coverage
4Core daemons evaluated
> OSS-FuzzExceeded 7.04% reported runtime coverage
  • Built an agentic workflow for source-code context mining, structured YAML extraction, daemon detection, and hybrid template generation.
  • Evaluated generated harnesses across BGP, PIM, OSPF, and Zebra under matched five-hour fuzzing conditions.
  • Improved overall line coverage beyond the manual baseline while reaching previously untested packet-processing logic.

02 2025

Securing Open-Source Software via Fuzz Testing

Evaluated the security posture of open-source software pre-installed on Ubuntu 24.04 LTS, using OpenSSF Scorecard to identify under-tested projects before applying targeted AFL++ fuzzing.

154OSS repositories assessed
57.8%Had no documented fuzzing coverage
36.99%KWAJ parser coverage
  • Constructed and analyzed a security dataset of GitHub-hosted Ubuntu packages using OpenSSF Scorecard.
  • Proposed refinements to security metrics by incorporating testing effectiveness, maintainer activity, and code coverage.
  • Developed AFL++ harnesses with AddressSanitizer and identified three crashes and two hangs in libmspack's KWAJ parser.
