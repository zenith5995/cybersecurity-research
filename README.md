## Publish with GitHub Pages

1. Create a new public GitHub repository, e.g. `research`.
2. Upload all files in this folder to the repository root.
3. Edit `index.html` and replace the placeholder `https://github.com/` links with your actual GitHub profile URL.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then save.
7. GitHub will publish the site at `https://YOUR-USERNAME.github.io/research/` if the repository is named `research`.

## Recommended resume QR setup

Point a static QR code at the GitHub Pages URL, not directly at either PDF. This lets you add or replace papers later without changing the QR code on your resume.
